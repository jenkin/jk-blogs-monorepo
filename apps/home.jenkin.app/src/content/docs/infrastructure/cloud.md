Even though I call myself self-hosting degen, sometimes I need the cloud for basic stuff and to expose public services without too many delivery or security issues.

## Basic services

Currently I'm using [Cloudflare](https://www.cloudflare.com/) for domains and DNS, [Github](https://github.com/) for code and static site hosting (yes, I know, I'm working on it), [Proton](https://proton.me/) for email services.

## VPS

I have two VPSs:
- a [VPS NL-1](https://mynymbox.net/vps) by MyNymBox for [headscale](/lab/tailscale/headscale) only
- a [VPS S](https://www.ionos.it/server/vps) by IONOS for [Zcash](/lab/services/zcash) exit node
